# Captrain design
Author: Nitish

## User experience

Closing the missing-capture-files banner permanently dismisses that warning on this PC, including after restarting the app. Other error messages remain visible normally.

Settings release notes display formatted headings, lists, emphasis, code and underlined links in the existing typography and theme. Keep the 180px scroll limit, wrap long URLs and allow keyboard focus on the scrollable region.

Item context menus offer Select mode. Entering selects that item; subsequent row clicks toggle selection instead of opening it, in list and grid views. A compact action bar shows the selected count, Select visible, Move, Save unsaved, confirmed Delete and Done. Selection is limited to loaded items and clears on filter changes or leaving the shelf; Show more extends the selectable items. Escape exits selection first. Batch Move reuses folder behavior, including exporting to permanent PC folders. Batch Save chooses one PC directory and skips items already marked exported, with exclusive filenames. Delete removes library originals only after one confirmation and preserves exported copies. Batch operations report partial failures, retain unfinished selections and prevent duplicate submissions.

Launch as a right-edge 16 × 72 logical-pixel hit area containing a 6 × 56 bar. Hover grows the bar inward, never opens it. Click opens a warm-white 540 × 740 shelf, clamped to the monitor work area. Left/right edge and display are settings. Match the supplied reference's compact utility layout: segmented All/Captures/Exports header, list/grid toolbar, pastel tabbed folders with counts, filename rows and an anchored capture/folder footer. Segoe UI Variable/Segoe UI, charcoal text, rounded shelf, restrained motion with reduced-motion support.

Drag the collapsed edge bar to any height on either the left or right edge of any connected display; it stays snapped to the nearest side edge of the display under the pointer. Save the display, edge and normalized vertical position on release. A click still opens the shelf; arrow keys on the focused bar adjust its height. Clamp the bar and opened shelf to the monitor work area, account for each monitor's DPI and negative coordinates, and fall back to the primary display if its saved display is disconnected. Existing settings retain centered placement.

The shelf morph starts and ends at the saved bar height and actual screen edge, matching the resting 6 × 56 bar. The open native window includes the panel's 10px edge gutter so the animation can reach that edge. Hold the final closing frame until native bounds return to the 16 × 72 hit area; hover updates during closing must not replace it with a centered bar in the expanded window.

The tray menu includes a persisted checked ?Shortcuts only (hide edge bar)? option. It hides the collapsed bar while keeping all existing global shortcuts active. Successful screenshots, links and finalized recordings show a compact non-activating Captrain desktop toast instead of opening the library, including when capture follows a manual shelf open. Errors and export warnings remain visible in the toast. The toast shares the native three-second dismissal timer, pauses on hover, and offers Open shelf and Dismiss. Tray Open shelf, tray left-click and the configured shelf shortcut still open the full library; recording setup and controls remain accessible through the video shortcut or tray. Disabling the option restores the saved bar position. Capture cancellation retains the previous mode; existing shortcut registrations and library contents are unchanged.

Library searches kind, localized date and filename with pagination and folder/export filters. Organizational folders support create, rename, delete without deleting captures, and moving captures. The footer's folder selects the destination for new captures; Settings separately selects an optional Windows directory for automatic PNG copies and exposes the current storage location. Originals remain in the private library, so disconnecting an output drive does not destroy history. Existing captures are never moved implicitly. Export copies survive deleting a library capture.

Clicking a thumbnail opens a separate owner-modal native viewer over the shelf, with previous/next navigation across the filtered library, fit/1:1/zoom controls, wheel zoom, pointer pan, Copy, Save as, Move to folder and confirmed Delete. Escape closes it. The parent shelf is disabled and held open until viewer close. Capture rows offer the same appropriate actions through a custom right-click menu with keyboard support; editable text retains its text-editing menu. No browser page menu on the app surface.

Instant capture is an explicit persisted setting, enabled by default. The main Capture button immediately executes the selected Region/Window/Screen action; its separate arrow changes type. Region immediately opens selection; direct Window captures the last external foreground window, remembered before shelf activation by a native foreground event hook. Disabling instant mode presents the action menu/window picker. A committed thumbnail animates into the shelf and settles into its row; reduced motion skips the flight. Settings retain transactional shortcut-conflict feedback. No Record placeholders or automatic clipboard replacement. Google account connection is optional; cloud access stays in Rust, with no remote content loaded in the web UI.

Save the active page in Chrome, Edge or Brave on Windows with Ctrl+Alt+4 (editable in Shortcuts), or Link in the capture dropdown using the last external browser window. Link is an immediate menu action with its own shortcut, alongside Region/Window/Screen; no separate footer link icon. Saved-link rows show the domain above the full URL and saved time, with one link tile and an open-in-browser indicator; only exported links carry a save badge. Native Windows UI Automation reads the visible document URL, falling back to an unambiguous address-bar URL; it never focuses controls, sends keystrokes, changes the clipboard, or reads page content. Only complete HTTP/HTTPS URLs without embedded credentials are accepted. Unsupported, inaccessible and ambiguous pages report an error without creating an item. Each saved link commits a local .url file and metadata atomically, appears under All and applicable folders/Exports, supports URL search, opens in the default browser and shares Copy, Save as, Move and Delete. Captures contains screenshots and recordings; image-viewer navigation contains screenshots only. Automatic disk copies also support .url files; failures retain the protected original. Existing screenshot history and custom shortcuts migrate without replacement.

Link also saves the active filesystem folder in Windows File Explorer with the existing Ctrl+Alt+4 shortcut or Link menu action. Shell automation resolves the foreground Explorer window and active tab without changing focus or clipboard contents; Home, This PC and ambiguous tabs report an error. Drive and UNC network paths are stored as validated file URLs in the existing link-item format, displayed and copied as Windows paths, and opened in Explorer. Folder links share organizational folders, search, export and deletion behavior with web links. Export saves a .url shortcut, never copies or deletes the target folder; an offline target does not invalidate saved history.

New links store their actual name in the existing title metadata: the browser document title (or browser window title when only the address bar is readable), or the decoded folder name. A missing browser title falls back to the hostname. Normalize whitespace and bound captured titles to 120 characters. The shelf and search reuse this persisted title; no network title fetching or page-content reading. Save as and automatic exports use Windows-safe readable .url filenames; automatic exports reserve each name exclusively and add (2), (3), etc. on collisions instead of UUID suffixes. Private storage continues to use owned IDs.

Both web and Windows folder links offer Rename in their context menu. A separate optional display title (1 to 120 characters) persists atomically and is searchable; the full target remains visible under the name. Renaming updates the suggested name for future exports, preserving the URL/path, private shortcut filename and previously exported copies. Legacy items without a title retain their previous automatic label and export name; existing files are not renamed or fetched again.

Settings > General offers System, Light and Dark appearance, with System retaining the previous Windows-following behavior. The persisted choice applies to the shelf and image viewer and is cached for first paint. Start with Windows is off until enabled; its switch reads and writes Captrain's quoted executable entry in the current user's Windows Run key, requires no administrator rights and starts the existing shelf bar at sign-in. Enable it from the installed copy. Windows Startup settings can independently disable startup.

## Video recording

The capture dropdown's Video action or Ctrl+Alt+5 (editable in Shortcuts) opens the recording island (see Recording island); the full setup for Screen, Window or Region stays one click away from it. No separate footer video button. Both capture menus use the short labels Region, Window, Screen, Video and Link, with Instant for the capture toggle. Menus containing checks reserve the same check column for every row, keeping labels aligned and shortcut hints right-aligned. Existing four- and five-action shortcut settings gain Video without replacing custom bindings; an unused fallback is chosen if Ctrl+Alt+5 is taken. Pressing the shortcut again closes an idle island or stops an active recording; it never starts devices directly. Screen-only is the default: system audio off, microphone off and webcam off. Optional devices are opened only after an explicit recording start with that source enabled. Source/device enumeration never starts capture. Region reuses the existing physical-pixel selector; Window uses native window capture, with no desktop-crop fallback. Choose 30/60 fps, Standard/High/Maximum bitrate presets, original/1080p/720p output without upscaling, cursor visibility and an optional three-second countdown. High quality and 60 fps are the initial defaults.

Optional microphone selection and system loopback audio mix into one AAC stereo track. The optional camera is baked into the video as a square inset, with four corner positions and three sizes. Circular masking and mirroring are not implemented in this version. No continuous preview. During capture the island shows the controls, and a red shelf bar also remains available; opening it reveals elapsed time excluding pauses, explicit device indicators, Pause/Resume and Stop. The shelf is excluded from capture. Capture actions, viewer opening, updater installation and tray Exit share recording exclusion; stop before exiting or updating. Completed MP4s appear under All/Captures and their destination folder, open in the default Windows video player, and support Save as, Move and confirmed Delete. Video clipboard copy is omitted.

## Brand identity

Keep the Captrain name and existing utility style. The canonical mark is `public/captrain.svg`: a flat muted-blue (#3d5f94) rounded cube silhouette with a bold warm-white (#fcfaf7) C angled onto its right face, matching Nitish's approved rounded-cube C image, preserving its soft curved letter terminals. Keep the background transparent; no gradients, outlines or extra decoration. The shelf's brand button retains Show everything; Settings pairs the mark with the Captrain name. Use the same mark for the favicon, native tray, executable and installer. Generate native sizes with `npx tauri icon public/captrain.svg --output src-tauri/icons`; retain only the Windows PNG/ICO assets. Preserve the application identifier and storage paths.

## Cloud backup

Settings includes Cloud backup after Save to disk. A contained Google Drive account header groups email, live operation status, last successful backup check and the primary Back up now action with Pause/Resume. Show hidden app storage and quota information immediately below, with expandable instructions for Drive Settings → Manage apps. Three labeled content tiles select screenshots, web links and videos; a separate history row explicitly warns when older items are excluded. Screenshots and web links start enabled; videos and existing history start disabled. Windows folder links and PC paths are excluded.

Import OAuth file uses a native JSON picker; Connect Google Drive uses the system browser. Developer setup is expanded for an unconfigured installation, collapsed once configured and absent when connected. Restore is a separate secondary action with additive behavior explained beside it. Reconnect, disconnect and retention details live under Account & backup options. Local deletion and disconnect keep cloud copies; cancellation finishes the current network request. Disable competing operations while busy; keep Cancel operation available. Preserve labeled native checkboxes, keyboard access, visible focus, live status, inline errors and both appearance modes. Paused, error and no-content-selected states take precedence over stale success messages. Keep this surface in Operate mode with the existing Windows utility typography and palette.

## Recording and path convenience

Recording setup remembers choices on this PC and explicitly names the selected screen or window. New installations retain screen-only defaults. When enabled, the three-second countdown appears on the target display with a visible outline, large countdown numeral, display/target label and keyboard-accessible Cancel/Escape. It covers the display so small regions cannot clip the controls, and disappears before recording begins.

All capture item context menus and the image viewer include Copy path with clipboard feedback and existing error reporting. Saved links copy the local .url file path through this action; their existing Copy action still copies the link target. PC-folder context menus include Copy path; virtual organizational folders do not expose a nonexistent disk path.

## Recording island

A dark, macOS-style notch flush with the top centre of a display holds all recording controls and is excluded from capture. It opens on the remembered recording display, or the pointer's display, and takes focus with Record focused. When ready it names the target (Display N, Region on Display N, or the last-used window's title), then offers Screen/Window/Region, System sound, Microphone and Webcam toggles, All recording settings (the full setup in the shelf), Record and Close (Escape). Every change is saved as a recording preference. Drag the pill, or its grip, onto another display to snap it to that display's top centre; with the grip focused, Left/Right arrows move it between displays. The island's display becomes the recording display. Window mode records the last external window used before the island took focus, and Record stays disabled until one exists. Microphone and Webcam use the remembered device or the first available one.

After Record, the island shows the countdown or Preparing state with Cancel, then a pulsing dot, the elapsed time, icons for the enabled devices, Pause/Resume and Stop, then Saving. State changes are announced to screen readers; timer ticks are not. The island closes after a recording is saved; after a cancelled or failed start it stays ready for another try. Recordings started from the full setup show the island too. The native window always matches the pill's size, so no invisible area blocks clicks. The island slides down from above the screen edge on open (300ms ease-out) and slides back up before every close (220ms ease-in). That includes Close, Escape, the shortcut toggle, opening the full setup and a saved recording. Record is a solid red pill with a white dot and label. The slide and pulse respect reduced motion.
